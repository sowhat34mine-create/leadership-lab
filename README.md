# Лидерство — интерактивный курс

Учебный проект по дисциплине **«Технологии коммуникации и принципы командообразования»**.
Интерактивная презентация о лидерстве: 14 слайдов, самодиагностика стиля лидерства,
симулятор управленческих решений и шпаргалка инструментов.

🔗 **Живая версия:** <https://sowhat34mine-create.github.io/leadership-lab/>

---

## Что внутри

| Блок | Содержание |
|------|-----------|
| **Коммуникация** | Модель передачи смысла (отправитель → получатель), 6 барьеров, выбор канала под тип сообщения |
| **Команда** | Пять стадий развития команды по Брюсу Такману: состояние, задача лидера, коммуникация, риск, инструмент |
| **Стиль лидерства** | Тест из 10 рабочих ситуаций → профиль: директивный / демократический / трансформационный / коучинговый |
| **Симулятор** | Пять решений нового руководителя с влиянием на доверие, вовлечённость и результат |
| **Инструменты** | Конструктор обратной связи SBI, уравнение доверия, 5 стратегий конфликта, словарь замен |

### Презентация

Кнопка **«Презентация»** в шапке открывает полноэкранный деск из 14 слайдов.

| Клавиша | Действие |
|---------|----------|
| `→` `←` `Space` | Следующий / предыдущий слайд |
| `Home` / `End` | Первый / последний слайд |
| `F` | Полный экран |
| `N` | Заметки докладчика |
| `Esc` | Закрыть презентацию |

Кнопка **«Скачать презентацию в PDF»** в подвале печатает деск в PDF
(формат 16:9, по одному слайду на страницу).

## Технологии

- Чистый HTML + CSS + JavaScript — без сборки и без зависимостей
- Тёмная и светлая темы, переключение запоминается в `localStorage`
- Адаптивная вёрстка, поддержка `prefers-reduced-motion`
- Доступность: семантическая разметка, `aria`-атрибуты, управление с клавиатуры, skip-link
- Полностью офлайн-совместимо: системные шрифты-fallback, SVG-иконки инлайн, никаких внешних зависимостей кроме шрифтов

## Структура

```

├── index.html          # разметка сайта и все 14 слайдов презентации
├── assets/
│   ├── style.css       # оформление, темы, адаптив, стили для печати

```

## Деплой на GitHub Pages

```bash
git remote add origin https://github.com/<owner>/<repo>.git
git push -u origin main
```

Затем в репозитории: **Settings → Pages → Build and deployment → Source: Deploy from a branch →
branch `main`, folder `/ (root)`**.
